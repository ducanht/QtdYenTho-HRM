# THƯ MỤC LƯU ẢNH TĨNH WEBAPP (IMAGES)

- Lưu các hình ảnh tĩnh của ứng dụng như: logo đơn vị, biểu tượng, banner, hình nền, ảnh trụ sở Quỹ...
- Đường dẫn truy cập trong Webapp:
  - `/images/ten-file.png`
  - Ví dụ: `<img src="/images/tru-so.jpg" />`
- Toàn bộ ảnh ở đây sẽ tự động deploy lên Firebase Hosting khi chạy lệnh `npm run ship`.
